# GuessTheState

A Python-based game where players guess the names of the states in the USA by typing them in a text input. The game uses the Turtle graphics library to display a map of the USA and highlights the states as they are correctly guessed.

## Features
- USA Map
- Real-time input for state names
- Highlights correctly guessed states on the map
- Displays the number of remaining states to guess
- Option to exit the game at any time

## Installation
Clone the repository:
git clone https://github.com/DarkKiraOG/GuessTheState.git
cd GuessTheState

Run the game:
python main.py

## How to Play
1. Upon starting, a map of USA will be displayed.
2. Type the name of a state in the input area and press Enter.
3. If the state is correct, it will be highlighted on the map.
4. Continue guessing until all states are correctly identified or click cancel to quit the game.

## Notes
- The game requires Python and the Turtle graphics library.
